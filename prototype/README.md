# 토우 친구들과 신라 발굴 도전 (초등판 시제품, 2026-10-20 도전판)

초등 5~6학년용 정적 웹 게임. 흙·돌·나무 3층을 손으로 파서 유물을 찾는다. **살살, 천천히. 유물을 깨뜨리지 말고.** 시간 제한은 없다.

- 플레이: https://created412.github.io/silla-tomb-dig-game/prototype/
- 설계: `docs/superpowers/specs/2026-10-20-challenge-dig-design.md`
- 구현 계획: `docs/superpowers/plans/2026-10-20-challenge-dig.md`

## 실행

빌드·설치 없음. 정적 서버 하나면 된다.

```sh
python -m http.server 5173 --directory prototype   # http://127.0.0.1:5173/
npm test                                          # Node 24, node --test
```

태블릿은 같은 와이파이에서 PC의 IP로 접속한다. 가로 화면 기준.

## 규칙

| 장치 | 내용 |
|---|---|
| 손맛 | 흙은 문지르기(셀당 0.6초), 돌은 톡톡 3번(0.25초 안에 4연타면 와르르 다시 쌓임), 나무는 붓으로 살살(셀당 0.9초, 0.12초 평균 속도가 초당 1200px를 넘으면 "살살!"). **흙에서 시작한 손놀림은 흙이 걷혀도 나무를 깎지 않는다.** 손을 뗐다가 나무 위에서 새로 시작해야 붓질 |
| ⚡ 금 | 유물 칸 위에서 나무를 **세게 문지르거나 찍으면** 먼저 🐸 경고, 3초 안에 또 하면 금 1개. 돌을 **연타해 무너뜨리면** 바로 금 1개. 3개면 유물이 깨져 실패 |
| 🪱 지렁이 | 흙 아래 몇 칸에 숨어 있다. 걷으면 튀어나와 🐸가 2초 도망간다 (그동안 입력 막힘) |
| 땅속 | 유물 위치·꽝 돌·지렁이는 판마다 다시 섞인다 |
| 토우 능력 | 한 판에 토우당 1번. 🐸 3×3 흙 걷기 · 🐢 3×3 돌 밀기 · 🐍 3×3 나무를 0.4까지 · 🐦 3초 동안 유물 자리 표시 |
| 📖 4컷 기억 조각 | 유물이 드러나는 동안 토우가 떠올리는 1500년 전 생활 장면 4컷이 끼어든다. 1컷: 유물 칸이 처음 나무까지 드러날 때, 2컷: 3칸 드러날 때, 3컷: 발견 뒤, 4컷: 질문(선택지 3개). 건너뛸 수 없고 오답은 개그 뒤 다시 고른다 |
| 🐢 합류 | 무덤을 처음 깨면 다음 무덤의 새 토우가 자기소개하며 합류한다 |
| 📚 토우 도감 | 제목 화면 "토우 친구들": 토우가 뭔지, 네 친구의 능력·성격·실제 토우 설명. 못 만난 토우는 실루엣 |
| ⭐ 별 | 금 0개 = 3개 · 1개 = 2개 · 2개 = 1개. 4컷 질문을 틀리면 1개 감점(최저 1개). 다음 무덤은 별 1개 이상이면 열림 |

실패해도 잃는 것은 없다. 그 무덤을 처음부터 다시 판다.

## 코드 구조

```
src/
  levels.js        레벨·유물 모양·토우 데이터·토우 소개 (교사가 고치는 곳)
  comics.js        4컷 대사·질문·선택지·오답 개그 (교사가 고치는 곳, 고증 승인 대상)
  art-dom.js       HTML 속 작은 캔버스에 토우·유물·4컷 그림 채우기
  challenge.js     한 판의 규칙: 무작위 배치, 금, 지렁이, 능력, 별 (순수, 테스트 있음)
  stars-store.js   별 저장·해금 (순수, 테스트 있음)
  dig-model.js     3층 손맛 모델 (순수, 테스트 있음)
  input.js         포인터 → 문지르기/탭/붓질 (테스트 있음)
  grid.js, hud.js, dialogue.js, lines.js
  main.js          단계 기계: title → card → (wake) → dig → found|broken|sunset → result
  effects.js       하늘·금·지렁이 오버레이
  renderer.js, terrain.js, characters.js, clay-art.js, generated-art.js, artwork.js  그리기 (Codex 작업분)
  artifact-stories.js  유물 이야기
assets/higgsfield/  배경·토우·재질·유물·4컷 시트·토우 선반 그림 (생성 기록은 *provenance.json)
tests/              node --test
```

콘솔에서 `sillaDebug.challenge`로 현재 판 상태(유물 칸, 지렁이, 금)를 볼 수 있다.

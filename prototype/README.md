# 토우 친구들과 두 무덤 모험

초등 5~6학년 대상, 천마총·황남대총에서 착안한 가상 발굴 놀이입니다. 잠든 토우를 얻고, 서로 다른 능력으로 길을 열며 두 무덤을 탐험합니다. 유물을 찾으면 시대·출토지·종류와 토우의 짧은 설명을 함께 봅니다.

## 실행

빌드와 외부 패키지가 없습니다. 저장소 루트에서 실행합니다.

```
python -m http.server 5173 --directory prototype
```

`http://127.0.0.1:5173/`에서 시작합니다. 가로 태블릿·PC를 권장하며 작은 화면에서는 이야기 화면을 세로로 스크롤합니다. 모든 에셋은 직접 그린 Canvas/SVG이고 외부 이미지·글꼴 요청이 없습니다.

## 놀이 흐름

1. 뱀 안내역과 시작해 두꺼비를 깨웁니다. 착지점을 정해 점프하면 흙길이 열립니다. 금관을 찾은 뒤 새, 말다래를 찾은 뒤 거북을 얻습니다. 새는 지도에서 날아갈 곳을 누르거나 화살표로 이동해 가까운 흔적을 조사하고, 거북은 선택한 돌을 받쳐 조사할 틈을 만듭니다. 두 번째 무덤은 새의 다른 공중 지도로 찾아갑니다.
2. 열린 구역에서 금관·천마 그림 말다래·유리잔 등을 발굴합니다. 흙은 문지르고, 돌은 세 번 두드리고, 나무는 천천히 쓸어 냅니다. 능력은 가상의 진입 경로에서 사용하며 유물에 직접 점프하거나 충격을 주지 않습니다.
3. 발견 직후 시대·나온 곳·쓰임을 소개합니다. 유물 그림의 번호 두 곳을 누르면 토우의 짧은 농담과 설명이 바뀝니다. 두 곳을 모두 눌러야 넘어가는 시험은 없습니다. 박물관에서도 유물을 고른 뒤 ‘유물 이야기 다시 보기’로 열 수 있습니다.
4. 유물마다 그림 두 개 중 하나를 고릅니다. 엉뚱한 선택에는 토우와 소품의 짧은 장난이 나오고, 두 번 틀리면 그림 힌트가 켜집니다. 점수는 깎이지 않습니다.
5. 기억 스티커 세 장으로 주인 실루엣을 꾸미고 별명을 붙입니다. 현대 소품 여섯 개는 튀어나가는 장난용이며 역사 단서로 붙지 않습니다.
6. 유물을 고른 뒤 빈 전시대를 누릅니다. 배치하면 1별, 얻은 설명 스티커까지 붙이면 3별입니다. 별 합계에 따라 벽지·바닥·조명 각 세 단계가 열립니다. 이미 전시한 물건은 다른 전시대로 옮기거나 서로 자리를 바꿀 수 있습니다.
7. 첫 전시의 설명 세 장을 붙이면 새와 두 번째 무덤으로 갑니다. 봉수형 유리병·금제 허리띠를 발굴하고, 두 봉분은 새와 함께 **땅 위에서 조사**합니다.
8. 둘째 주인을 꾸미고 여섯 전시의 설명을 완성하면 두 이야기의 마지막 인사를 봅니다. 지도에서는 완료한 무덤의 유물을 다시 파볼 수 있습니다. 다시 파기는 기존 전시와 별을 바꾸지 않습니다.

거북은 드러난 돌 한 칸을 깨 주고, 새는 유물 위치를 5초 동안 표시합니다. 본 탐험에서 각 동료의 능력은 무덤마다 한 번입니다. 다시 파기에서는 손맛 발굴만 반복합니다.

위 문단의 발굴 보조 능력은 길을 여는 조작과 별개입니다. 점프·공중 탐색·돌 틈 놀이는 ‘토우 능력’ 메뉴에서 다시 할 수 있습니다. 이미 얻은 토우는 중복 지급되지 않습니다. 예전 저장에서 이미 함께하던 친구와 전시는 유지되며 새 능력 경로만 추가로 열어갑니다.

## 저장

`localStorage`의 `silla-adventure-v1`에 기억·주인·전시 배치·꾸미기·도움 사용과 발굴 중간 상태를 저장합니다. 손을 뗄 때 파던 층이 저장되고 다음 접속에서 복원됩니다. 다시 파기의 중간 상태는 저장하지 않습니다. 저장이 차단되어도 현재 창에서 진행할 수 있으며 화면에 저장 불가를 알립니다.

예전 `silla-first-exhibit-v1`의 완성 전시가 있으면 첫 전시로 가져옵니다. 예전 저장 키를 덮어쓰지 않습니다. 이전 학습 연결·사례 판단 모듈은 호환 검사를 위해 남아 있으나 새 기본 진행에서는 사용하지 않습니다.

## 검사

```
npm test
npm run test:adventure
npm run test:story
npm run test:companions
```

기존 보호된 발굴·입력·대사 검사 33개, 새 모험·보상·저장 검사 9개, 이전 전시 호환 모듈 검사 15개입니다.

토우 획득 조건·경로 해금·착지/비행 조사·중복 보상·저장 검사 4개는 `test:companions`로 실행합니다. 브라우저 검사는 토우 획득, 금관 설명, 새 탐색 화면에서도 검토를 위해 멈추며 ‘계속 검사’로 이어갑니다.

브라우저 검사는 저장소 루트에서 `python tools/serve-visual.py`를 실행한 뒤 `http://127.0.0.1:5175/tools/adventure-check.html`을 엽니다. ‘두 무덤 전체 검사’를 누르고, 첫 주인·첫 전시 화면에서 각각 ‘계속 검사’를 누릅니다. DPR 2의 실제 포인터 입력으로 두 탐험, 중간 저장 복원, 오답 장난, 동료 도움, 스티커, 전시·꾸미기, 결말, 재접속, 다시 파기를 검사합니다. 검사는 메모리 저장소를 사용하므로 실제 플레이 저장을 건드리지 않습니다.

## 범위와 기록

혼자 플레이하는 두 무덤 시제품입니다. 반 코드·온라인 공유·친구 박물관 방문·음성 안내·세 번째 무덤은 구현하지 않았습니다. 별명은 세 가지 제안 중 고릅니다. 실제 유물 사진과 실제 인물의 복원 초상은 사용하지 않습니다.

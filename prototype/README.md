# 초등판 0차 손맛 시제품

무덤 1(천마총 기반)의 흙·돌·나무 3층을 파 내려가 금관 1개를 드러내고, 뱀·개구리 토우 만담 2개가 나오는 브라우저 시제품입니다. 목적은 하나, 아이 3~5명이 끝나고 "또 파고 싶어?"에 "응"이라고 하는지 보는 것입니다.

계획서: `docs/plans/01-초등용-게임계획서.md` (6-1 "3층 뚫기 발굴", 12-1 "0차 손맛 시제품")

## 실행

빌드 없음. 정적 서버 하나면 됩니다.

```
python -m http.server 5173 --directory prototype
```

브라우저에서 `http://127.0.0.1:5173/` 을 엽니다. 태블릿은 같은 와이파이에서 PC의 IP로 접속합니다(가로 화면 권장).

## 테스트

```
npm test
```

순수 로직(발굴 모델·대사 큐·격자 좌표)만 테스트합니다. 렌더러·입력·소리는 브라우저에서 눈으로 확인합니다.

## 조작

| 층 | 조작 |
|---|---|
| 1층 흙 | 손가락(마우스)으로 문지르기. 셀당 약 0.6초 |
| 2층 돌 | 톡톡 두드리기 3번. 0.25초보다 빠르게 4연타하면 "와르르" 돌이 다시 쌓임(손해 없음) |
| 3층 나무 | 붓으로 살살. 빠르게 문지르면 진척 없이 🐸 "살살! 살살!" |

금관 6칸이 다 드러나면 플래시·소리·확대 뒤 만담 2가 나오고 "또 파고 싶어?" 화면이 뜹니다.

## 검증 기록

"응, 또!" / "아니" 선택과 발굴에 걸린 시간이 브라우저 `localStorage`의 `silla-proto-log` 키에 JSON 배열로 쌓입니다. 개발자 도구 콘솔에서 확인합니다.

```
JSON.parse(localStorage.getItem('silla-proto-log'))
```

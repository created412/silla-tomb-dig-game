# 초등판 첫 무덤 이야기 시제품

천마총에서 착안한 가상 발굴 놀이입니다. 금관을 찾으면 거북 토우가 합류하고, 말다래와 유리잔을 더 찾아 세 단서로 주인의 삶을 짐작합니다. 진짜 이름은 아직 모른다고 구분한 뒤 별명을 붙여 첫 전시를 완성합니다.

계획서: `docs/plans/01-초등용-게임계획서.md` (6-1 "3층 뚫기 발굴", 12-1 "0차 손맛 시제품")

## 실행

빌드 없음. 정적 서버 하나면 됩니다.

```
python -m http.server 5173 --directory prototype
```

브라우저에서 `http://127.0.0.1:5173/` 을 엽니다. 태블릿은 같은 와이파이에서 PC의 IP로 접속합니다(가로 화면 권장).

## 테스트

```
npm test
npm run test:story
```

기존 발굴·입력·대사 검사 33개와 새 이야기·저장 검사 8개입니다. 렌더러와 전체 연결은 아래 브라우저 도구로 확인합니다.

## 조작

| 층 | 조작 |
|---|---|
| 1층 흙 | 손가락(마우스)으로 문지르기. 셀당 약 0.6초 |
| 2층 돌 | 톡톡 두드리기 3번. 0.25초보다 빠르게 4연타하면 "와르르" 돌이 다시 쌓임(손해 없음) |
| 3층 나무 | 붓으로 살살. 빠르게 문지르면 진척 없이 🐸 "살살! 살살!" |

각 유물의 6칸을 드러내면 2.6초의 발견 연출 뒤 대사가 이어집니다. 연출 중 탭으로 대사가 넘어가지 않습니다. 두 특징을 관찰하고 근거에 맞는 추론을 고르면 다음 유물로 갑니다. 후속 두 유물은 이미 내려온 나무 바닥 구역에서 붓질로 찾습니다.

## 비주얼 개선판

흙·돌·나무 재질을 캐시하고 흙과 나무를 둥근 불규칙한 구멍으로 걷어 냅니다. 돌은 1·2타 때 균열이 생기고 3타 때 조각이 튑니다. 토우 친구는 점토에서 착안해 직접 그린 창작 캐릭터이며, 반응·대사·발견에 맞춰 표정과 움직임이 달라집니다.

금관은 出자 세움 장식 3개, 사슴뿔 장식 2개, 곡옥·달개·드리개를 그린 교육용 벡터 도판입니다. 실측 복원도가 아닙니다. 발굴 중에는 기존 6칸 모델에 맞춘 금띠를, 발견 뒤에는 비율을 유지한 전체 금관을 보여 줍니다. 외부 이미지·글꼴·패키지 요청이 없습니다.

가로 태블릿·PC 대상으로 1024×600 이상에서 화면을 확인했습니다. 세로 휴대폰과 높이 420px 미만 화면은 이 시제품의 검증 범위 밖입니다. 시스템의 동작 줄이기 설정에 따라 흔들림·반짝임·캐릭터 움직임을 줄입니다.

검증 기록과 전후 화면: [비주얼 검토](../docs/visual-review/README.md).

추가 브라우저 검증은 저장소 루트에서 `python tools/serve-visual.py`를 실행하고 `http://127.0.0.1:5175/tools/visual-check.html`을 엽니다. 캐시를 끈 로컬 서버이며, 두 검사 버튼으로 실제 입력 경로와 재시작·기록을 확인합니다. `visual-gallery.html`은 검토용 부분 발굴 상태와 장면별 배치, CPU 렌더링 비용을 확인하는 도구입니다. 이 도구는 게임에 포함되지 않습니다.

## 검증 기록

전시 완성 후 "다시 발굴하기" / "첫 화면으로" 선택과 세 유물의 총 발굴 시간이 `localStorage`의 기존 `silla-proto-log` 키에 쌓입니다. 완성 전시는 `silla-first-exhibit-v1`에 저장되며 첫 화면의 "내가 만든 전시 보기"에서 열 수 있습니다. 발굴 중간 진행은 저장하지 않습니다. 저장이 차단되어도 플레이와 현재 전시 관람은 가능합니다.

```
JSON.parse(localStorage.getItem('silla-proto-log'))
```

## 아직 없는 것 (1차 학교판 범위)

둘째 무덤, 여러 전시를 모으는 박물관, 주인 꾸미기, 새 토우 합류, 반 코드, 음성 안내, 실제 유물 사진.

실제 유물 사진은 사용하지 않습니다. 관찰·추론의 고증 출처와 구현 범위는 [첫 이야기 검토](../docs/visual-review/story.md)를 참고하세요. 수업 시간과 어린이의 이해도·흥미는 실제 플레이 관찰이 필요합니다.

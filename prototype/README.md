# 토우 탐험대 — 능력으로 신라 발굴

초등 5~6학년용 정적 웹 게임. 힉스필드 그림을 적용한 2026-10-20 재구성판이다.
시작 주소는 `prototype/index.html`, 상대 경로만 사용한다. 빌드나 설치 의존성이 없다.

## 실행

```sh
python -m http.server 5173 --directory prototype
npm test
node --test tools/quest-model.test.js
```

프로젝트 루트를 서비스하면 `tools/quest-check.html`에서 분리된 메모리 저장으로
실제 포인터 입력·단계 진행·수동 저장 전체 검사를 실행할 수 있다.

## 진행

1. 흙 세 곳을 걷어 두꺼비를 깨운다. 두꺼비로 넓은 흙을 걷고 금관을 발굴하면 새가 합류한다.
2. 새로 위치를 찾아 말다래를 발굴하면 거북이 합류한다.
3. 두꺼비로 흙을 걷고 거북으로 돌을 밀어 유리잔을 찾으면 뱀이 합류한다.
4. 다음 무덤으로 바로 이동해 네 친구로 봉수형 유리병을 찾는다. 뱀이 나무 틈을 연다.
5. 네 능력을 조합해 금제 허리띠를 발굴한다.
6. 새를 날려 두 봉분을 조사하면 여섯 기억의 지도가 완성된다. 열린 발굴터는 재플레이 가능하다.

토우 선택 → 표시된 자리 또는 발굴판 누르기 → 층이 실제로 걷힘 → 손과 붓으로 마지막 마무리.
전시는 선택 활동이며 다음 구역을 여는 조건이 아니다. 유물 설명은 발견·전시·기억 지도에서 다시 볼 수 있다.

## 저장

오직 `저장하기` 버튼만 기기 저장을 쓴다. 진행·보상·화면 이동은 자동 저장하지 않는다.
새로 시작해도 저장하기 전에는 이전 기록을 바꾸지 않는다.

- 새 키: `silla-towoo-quest-v2`.
- 기존 `silla-adventure-v1`은 읽어 수집 진행을 옮기지만 삭제하거나 자동 덮어쓰지 않는다.
- 예전 다섯 유물을 모두 모았던 기록은 마지막 두 봉분 조사부터 이어진다.
- 새 획득 순서를 처음부터 체험하려면 `탐험 새로 시작하기`를 누른다.
- 재발굴은 본편 발굴 저장을 덮어쓰지 않는다. 저장 실패도 이전 기록을 보존한다.

## 그림과 근거

토우·두 무덤 배경·발굴 재질·보상 유물·전시실에 힉스필드 생성 그림을 적용했다.
총 다섯 장, 실제 사용 1.25크레딧. 플레이 중 추가 AI 호출이나 크레딧 사용은 없다.
유물 그림은 특징을 살린 놀이용 삽화이며 실측 복원도가 아니다.
시대·출토지·쓰임은 `artifact-stories.js`의 기존 박물관·우리역사넷 자료에 근거한다.
생성 정보는 `assets/higgsfield/{provenance,quest-provenance}.json`에 기록했다.

## 코드 및 검증

- `src/quest-model.js`: 새 진행·능력·저장 모델.
- `src/quest-main.js`, `quest.css`: 화면과 실제 입력 연결.
- `src/generated-art.js`, `clay-art.js`: 로컬 캐시·아틀라스 처리.
- 기존 보호 대상 발굴/격자/입력/대사/HUD 및 `tests/`는 그대로다.
- 기존 33개, 새 진행 모델 6개 검사 통과. 브라우저 전체 모험 검사 63개 통과.
- 옛 `main.js`, `adventure-ui.js`, 관련 검사 페이지는 이전 전시 중심 판의 기록이다.

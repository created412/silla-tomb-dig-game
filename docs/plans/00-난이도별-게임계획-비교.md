# 신라 고분 발굴 게임: 초등·중등·고등 3단계 계획

2027학년도 사용 · 2022 개정 교육과정 기준 · 작성 2026-10-18 · 기획안 v2.0

## 1. 전체 방향

같은 신라 발굴 현장을 공유하되, 학생이 해결하는 질문과 만드는 결과물을 다르게 설계한다. 난이도는 암기량·시간 압박·클릭 횟수보다 자료의 수, 판단 단계, 도움의 정도로 조절한다.

| 구분 | 초등: 발견 | 중등: 탐구 | 고등: 기출 분석 |
|---|---|---|---|
| 별칭 | 토우 친구들과 무덤 주인 찾기 | 천마총 증거 수사대 | 신라에서 시작하는 문화사 감정실 |
| 기본 대상 | 초등 5~6학년 | 중학생, 중3 역사 수업 중심 | 고등학생, 한국사1 학습·수능 문화사 복습 |
| 핵심 질문 | 이 무덤의 주인은 누구였을까? | 어떤 근거로 신라 문화를 설명할까? | 시대·국가를 가르는 단서는 무엇일까? |
| 사고 과정 | 발굴 → 유물 단서로 주인 추론 → 알 수 있는 것과 없는 것 구분 | 관찰 → 비교 → 주장과 근거 → 한계 | 자료 해석 → 시대·국가 판별 → 선지 검증 → 전이 |
| 필수 자료 | 천마총 금관·천마도 말다래·유리잔 | 천마총 유물 3개와 비교 자료 | 신라 자료 + 실제 기출의 다른 시대 자료 |
| 놀이 중심 | 흙·돌·나무 3층 발굴, 오답 코미디 카드, 토우 친구, 주인 꾸미기, 내 박물관 | 구조 퍼즐, 증거 보드, 전시 설명 | 감정 의뢰, 잘못된 전시 분류 수정, 기출 도전 |
| 질문 형식 | 그림 선택지 2개, 오답은 코미디로 근거 설명 | 근거 2개 연결, 비교·판단 유보 | 원문 기출 5지선다, 결정 단서·오답 근거 |
| 도움 | 토우 친구가 먼저 반응, 읽어 주기 | 요청형 힌트·용어 풀이 | 연습은 단계 힌트, 실전은 제출 뒤 해설 |
| 기본 플레이 | 20분 | 25분 | 30분 |
| 수업 | 40분 | 45분 | 50분 |
| 결과물 | 주인 꾸미기·이름, 설명판이 달린 내 박물관 | 근거가 달린 전시 설명 3개 | 문화사 감정 기록과 오답 분류표 |
| 학습 판정 | 유물 근거 하나 + 아직 모르는 것 하나를 말함 | 자료로 문화의 특징을 분석 | 정답뿐 아니라 단서·탈락 이유를 설명 |

학교급 선택은 권장 시작점이다. 모든 모드를 처음부터 열어 두고, 학생이 원하면 더 쉬운 도움 방식이나 다른 난이도를 선택할 수 있게 한다. 하위 단계를 깨야 다음 단계가 열리는 구조는 사용하지 않는다.

초등은 2022 개정 사회 [6사04-02], 중등은 역사 [9역08-03], 고등의 중심 탐구는 한국사1 [10한사1-02-04]에 연결한다. 세부 출처·학습 범위는 각 계획서에 명시했다. 고등의 모든 기출 문제가 이 성취기준 하나에 해당하는 것은 아니며, 정치·사회와 결합된 문항은 별도 표시한다.

**2027학년도에 고3이 치르는 수능은 2028학년도 수능이다.** 기존 기출은 출제 당시 교육과정 자료로 표시하고, 2022 개정 내용과 맞는 부분을 선별해 재사용한다. 아직 치러지지 않은 2028학년도 수능 기출을 제공한다고 표기하지 않는다. [교육부 2028 수능 안내](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=340&boardSeq=102604&lev=0&m=020201&opType=N&page=26&s=moe)

## 3. 같은 유물을 다르게 쓰는 예

| 공통 소재 | 초등 | 중등 | 고등 |
|---|---|---|---|
| 천마도 | "주인은 말을 탔을까?" 단서 카드, 오답은 말다래를 등에 멘 코미디 | 고구려 벽화와 그림이 있는 대상·위치를 비교하기 | 문화유산 카드의 국가·시대·매체 설명 중 오류 찾기 |
| 금관 | "이걸 쓴 사람은?" 단서 카드로 높은 사람 추론 | 무덤 규모와 묶어 사회적 지위 해석 | 금관만으로 가능한 추론과 특정 왕 확정 주장을 구별하기 |
| 고분 구조 | 흙·돌·나무 3층을 직접 파 내려가는 발굴 손맛 | 돌무지덧널무덤과 돌방·벽돌무덤 비교 | 여러 자료 중 국가 식별에 유효한 단서 선별하기 |
| 다른 지역·시대 유물 | 유리잔 "어디서 왔을까?" 단서 카드 | 교류 추론과 판단의 한계 | 실제 기출 자료·선지의 시대 분류와 오답 제거 |

고등의 천마도·금관 활동은 자체 제작 활동이다. 확인한 기출에 나오지 않은 내용을 ‘수능 기출’이라고 부르지 않는다.

## 4. 공통으로 만드는 부분

로그인 없는 PC·태블릿 웹 게임, 2D 평면·단면 발굴 화면, 유물 확대, 기록 수첩, 기기 내 저장, 이어하기, 결과 인쇄·텍스트 저장을 공유한다. 초등판은 여기에 로그인 없는 경량 코드 기반 서버(반 코드·박물관 코드로 박물관 구성을 올리고 내리는 수준)를 추가로 쓴다. 유물 이름·출토지·재료·시대·출처 데이터는 한 벌을 사용하고, 설명 문장·질문·힌트·평가 규칙을 난이도별로 둔다.

키보드·터치·드래그 대체 버튼, 음소거, 글자 확대를 공통 지원한다. 초등의 읽어 주기는 핵심 지시·해설 음성으로 제공하고 텍스트를 함께 표시한다. 초등 음성은 다른 단계에서도 선택할 수 있다.

공통 고증 원칙은 다음과 같다.

1. 천마총을 바탕으로 한 교육용 디지털 재구성임을 표시한다. 실제 발굴 배치·순서의 정밀 재현이라고 주장하지 않는다.
2. 천마도는 말다래에 그린 그림이며 벽화가 아니다. 보존이 필요한 재질은 전문가 인계 후 복제 이미지로 관찰한다.
3. 황남대총 유리잔·다른 시대 유물은 별도 비교실 자료다. 신라 고분 안에서 고려 책이나 조선 유물을 발굴하게 하지 않는다.
4. 모든 신라 무덤을 하나의 양식으로 일반화하지 않으며, 금관만으로 왕의 이름·성별·골품을 확정하지 않는다.
5. 실수하면 자료를 다시 관찰하고 수정한다. 유물 판매·희귀도 뽑기·연타 보상·영구 손상은 두지 않는다.

## 5. 제작 순서와 범위

제작 순서는 **초등판 독립 제작(2027년 1학기 전) → 공통 발굴 시제품 → 중등 기준판 → 고등판**이다. 초등판은 발굴 화면·저장 구조를 공유하지 않고 유물 데이터 파일만 함께 쓴다(2026-10-19 사용자 결정). 중등·고등은 공통 시제품 위에 올리며, 중등판에서 유물·구조·비교 데이터의 정확성을 먼저 확보하고 고등판에 기출 감정실을 덧붙인다.

| 단계 | 완료 산출물 | 검증 조건 |
|---|---|---|
| 내용 확정 | 학교급별 교과서 대응표, 유물·문항 출처표 | 기출·자체 제작 구분, 정답·도판·출토지 확인 |
| 공통 시제품 | 유물 1개 발견→관찰→설명 5분 | 조작을 이해하고 발견 과정에 흥미를 느끼는지 관찰 |
| 세 버전 완성 | 각 계획서의 필수 활동·결과 저장 | 초등 20분·중등 25분·고등 30분 전 과정 진행 |
| 사용 검증 | 학교급별 소규모 사용 및 문항 검수 | 시간, 읽기 부담, 오개념, 근거 설명 능력 확인 |

학교급별 5~8명 정도의 소규모 검증으로 시작하되 효과를 일반화하지 않는다. 80% 이상이 목표 시간 안에 핵심 활동을 마치는 것을 초기 목표로 삼는다. 정답률만으로 재미나 학습 효과를 판정하지 않고, 막힌 지점·도움 요청·자발적 설명도 기록한다.

실시간 멀티플레이, 대형 3D 월드, 생성형 AI 자유 대화, 로그인 기반 학급 관리, 문화사 전 범위 문제은행은 첫 버전에 포함하지 않는다. 초등판의 코드 기반 박물관 공유는 예외로 포함한다. 개발 기술과 미술 제작 방식은 구현 담당자가 선택할 수 있다. 기간·비용은 이 선택 뒤 산정한다.

## 6. 현재 확정 수준

2027년 사용과 2022 개정 기준, 세 학교급 분리, 고등의 수능 문화사 기출 활용은 사용자 요청 사항이다. 초등 5~6학년, 플레이 시간, 2D 웹 방식, 고등의 ‘신라 발굴+시대 비교 감정실’ 구성은 기획 제안이다. 교과서 출판사와 최종 탑재 기출 목록·원문 이용 조건은 제작 단계에서 확정한다. 현 단계는 계획서이며 게임·전체 문제은행을 구현한 상태가 아니다.

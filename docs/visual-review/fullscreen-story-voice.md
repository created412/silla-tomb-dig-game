# 큰 그림책 대화와 ElevenLabs 음성 — 2026-10-21

사용자 요청: 아래쪽 작은 대화창을 모든 대화에 걸쳐 전체 화면 만화로 바꾸고, 유아·초등 대상에 맞는 ElevenLabs 음성을 넣는다.

구현:
- 시작·발견·실패·결과·발굴 중 반응 대사에 큰 그림 + 화자 그림 + 큰 글씨 + 직접 넘기는 버튼을 적용했다.
- 유물 기억 네 컷, 질문과 오답 피드백, 새 토우 합류도 같은 화면으로 통일했다.
- 발굴판 레이아웃 상수는 그대로다. 이야기 표시 중에만 발굴 입력을 막는다.
- 반응 대사 자동 넘김을 없앴다. 반복 반짝임 안내는 한 판에 한 번만 띄운다.
- 힉스필드 GPT Image 2.5 low/1k로 네 장면짜리 아틀라스 한 장 생성: 0.25크레딧. 잔액 64.61 → 64.36. 출처: `prototype/assets/higgsfield/dialogue-provenance.json`.
- 음원 재생·이전 음성 중단·다시 듣기·음소거를 연결했다. 재생 속도 0.9, 음성 완료가 대사를 자동으로 넘기지 않는다. 브라우저 음성 합성으로 대체하지 않는다.

음성:
- 사용자가 직접 생성을 진행하고 음원까지 반영해 푸시하라고 지시하여 기본 목소리를 선정했다. Higgsfield `text2speech_v2`, `variant: elevenlabs`, preset Faye(두꺼비·새)와 Arthur(뱀·거북).
- 한국어 음원 79개, 원본 합계 427.84초, 약 6.93MB. 게임 내 재생은 0.9배속이다. 숫자와 세기 표기는 읽기 쉬운 한글로 정규화했다.
- 첫 문장 견적 0.15, 긴 설명 견적 0.45크레딧. 전체 실사용 14.65크레딧, 잔액 64.36 → 49.71. 새 만화 그림까지 이번 변경 총 14.90크레딧. 재생 시 생성 요청 없음.
- `prototype/assets/voices/jobs.json`에 실제 입력 문구·목소리·작업 ID·결과 URL을 보관한다. `manifest.json`은 79개 로컬 MP3에 연결한다.
- `tools/voice-catalog.mjs`는 대사 목록을 만들고, `tools/download-voices.py`는 이미 생성된 결과만 내려받는다. 둘 다 유료 생성 API를 호출하지 않는다.

검증:
- `npm test`: 기존 65개 통과. 보호 파일 및 `prototype/tests/` 변경 없음.
- `node --test checks/voice-player.test.mjs`: 지연 로딩 경쟁, 대사 전환 중단, 다시 듣기·음소거 검사 통과. 가짜 오디오로 제어만 검증했으며 실제 음질 검증은 아님.
- `checks/crown-completion.html`: 실제 포인터로 여섯 곳 발굴 → 기억 네 컷 → 거북 → 다음 무덤, 9개 통과.
- `checks/story-screen.html`: 모든 반응 대사, 자동 소멸 없음, 27px 이상 본문, 대화 전후 발굴판 동일, 대화 중 입력 차단, 질문·합류, 25개 통과.
- 1440×731 기본 화면, 1024×768 태블릿, 390×844 세로 화면에서 시각 확인.
- 79개 MP3 모두 디코딩·재생 길이 검사 통과. 첫 대사, 긴 유물 설명, 질문, 거북 합류 일부를 로컬 Whisper로 전사해 시작과 끝 내용 포함 여부 확인. 자동 전사는 오인식이 있으며 사람의 청취 검수는 아니다.
- 실제 Chrome에서 첫 대사 MP3가 0.9배속으로 재생되는 것, 다음 버튼으로 음원이 교체되는 것, 음소거로 정지되는 것을 DOM 미디어 상태로 확인했다.

사용자 요청으로 `prototype/dig-0`에 푸시해 GitHub Pages로 배포한다. `tmp/`는 기존 사용자 작업이므로 건드리지 않는다.

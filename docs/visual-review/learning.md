# 무엇을 배우는지 드러내기

이 문서는 이전 실험 기록입니다. 사용자의 난이도·재미 피드백에 따라 기본 진행을 [놀이 중심 두 무덤 모험](adventure.md)으로 교체했습니다.

## 수정 이유

이전판은 세 유물을 찾고 설명을 읽은 뒤 정답을 선택하면, 자동 설명판이 있는 전시로 끝났다. 학생이 설명의 근거를 연결하거나 새로운 상황에 적용한 흔적이 남지 않았다. 유물 수집을 완료한 것을 학습의 완료처럼 취급한 점이 문제였다.

## 내용과 학생의 행동

| 배우려는 내용 | 학생이 하는 행동 | 남기는 결과 |
|---|---|---|
| 금관으로 짐작하는 높은 지위 | 높은 지위 장면에 금관을 고르고, 금과 화려한 장식을 근거로 연결 | 유물·특징·생활의 연결 기록 |
| 말다래의 쓰임과 말을 타는 생활 | 말 그림의 모양만 보지 않고 안장 부속품이라는 쓰임을 근거로 선택 | 쓰임에 근거한 생활 장면 |
| 먼 지역과 물건의 교류 | 유리잔의 푸른색이 아니라 먼 지역의 유사한 유리그릇과 비교한 점을 근거로 선택 | 지역 사이 물건 이동의 가능성을 표현한 장면 |
| 단서가 말해 주는 범위 | 다른 가상 무덤의 말다래만으로 왕이나 모든 신라인의 생활을 확정할 수 있는지 판단 | 첫 판단과 수정한 판단 |
| 발견하지 못한 것과 원래 없는 것의 차이 | 금관 미출토만으로 낮은 지위를 확정할 수 있는지 판단 | 추가 자료가 필요하다는 판단 |

전시 전 ‘기억 공방’에서 유물과 근거를 모두 연결하면 생활 그림이 드러난다. 그림은 근거로 꾸민 상상 장면으로 표시한다. 실제 인물의 복원도나 초상이 아니다. 이후 ‘옆 무덤의 조사 편지’ 두 사례에 적용하고, 그 뒤에 별명을 붙여 전시한다. 사례는 가상이라고 명시한다.

전시에서 ‘내가 설명한 것과 고친 생각 보기’를 누르면 연결한 근거, 첫 판단, 수정한 판단이 보인다. 첫 선택을 고쳐도 첫 판단 기록은 덮어쓰지 않는다. 틀린 횟수로 감점하거나 학습 능력 등급을 매기지 않는다. 이전 버전 전시는 그대로 열 수 있지만 새 활동 기록이 있는 것처럼 표시하지 않는다.

## 학습 효과에 대해 말할 수 있는 범위

이번 구현으로 확인하는 것은 게임 안에서 근거를 연결하고 사례에 판단을 적용했는지다. 자유 서술 능력·장기 기억·다른 실제 유물로의 전이까지 검증한 것은 아니다. 선택지의 오답은 초등용으로 명확하게 구분했으므로, 숙련된 학생에게는 쉬울 수 있다. 교사가 ‘이 유물이 왜 그 설명의 근거야?’를 선택지 없이 물었을 때 답할 수 있는지 실제 플레이로 확인해야 한다.

학생에게 확인할 질문:

- 금관의 어떤 점을 보고 높은 지위라고 생각했니?
- 말다래가 무엇에 쓰였는지 설명할 수 있니?
- 유리잔이 푸르다는 이유만으로 외국 물건이라고 해도 될까?
- 금관이 나오지 않은 무덤의 주인은 낮은 지위라고 해도 될까?

고증 출처와 사실·가상 장면의 구분은 [첫 이야기 검토](story.md)의 출처를 유지한다. 새 학습 데이터는 `learning-data.js`, 완료 조건과 기록은 `learning-model.js`, 화면은 `learning-view.js`에 있다.

## 검증

기존 보호 파일/테스트는 변경하지 않았다. `npm test` 33개와 `npm run test:story` 15개로 기존 발굴, 근거 없는 완료 방지, 첫 판단 보존, 새 저장 기록 검증, 예전 전시 호환을 확인한다. 브라우저 통합 검사는 생활 연결과 새 사례를 포함하도록 확장했다.

2026-10-20 검증: 1024×600 게임 영역/DPR 2에서 브라우저 59개 확인 통과, 콘솔 error/warn 없음. 오답 수정 뒤에도 첫 판단이 남고, 새로고침 후 다시 연 전시에서 탐구 기록이 표시된다. 작은 화면의 오답 초점 문제는 재현 후 수정했으며 키보드 Enter로 근거 선택도 확인했다.

## 다음 작업에서 지킬 절차

1. 제목·스타일·제외 항목·모델을 파일로 먼저 보관한다.
2. 생성은 한 번 누르고, 새 곡 카드와 고유 링크가 나타나는지 확인한다. 회전 표시가 유지되는 동안 중복 제출하지 않는다.
3. 생성 폼을 새로고침하거나 다른 페이지로 이동하지 않는다. 필요하면 별도 라이브러리 탭으로 결과를 확인한다.
4. 보안 확인이 실제로 나타나면 사용자에게 그 화면을 넘긴다. 실패를 반복 클릭이나 보안 우회로 해결하지 않는다. 쿠키 삭제·확장 프로그램 비활성화·로그아웃을 임의로 수행하지 않는다.
5. 같은 오류가 반복되면 현재 입력과 증거를 보존하고, 사용자가 직접 생성한 곡 링크 또는 기존 소유 Suno 곡 활용 중 원하는 방법을 확인한다. 기존 곡을 새로 생성한 곡이라고 설명하지 않는다.
6. 실제 MP3를 확보한 뒤에만 배포한다. 생성 출처·곡 링크·파일 길이·검증 결과를 기록하고 라이브 사이트에서도 재생을 확인한다.

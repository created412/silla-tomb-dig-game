# 원안의 혼자 플레이를 되살리기

사용자 피드백: 교육적이지만 어렵고 재미없다. 직관적인 재미, 긴 이야기, 원래 계획과의 일치가 필요하다.

이전 필수 관찰 2회·근거 3지선다·다른 사례 시험·학습 기록은 기본 진행에서 제외한다. 기존 파일과 이전 저장값은 보존한다. 원안의 ‘한 화면 한 지시, 그림 선택지 2개, 짧은 오답 코미디’를 복원한다.

구현 범위는 혼자 플레이의 연속된 두 이야기다. 첫 무덤의 금관·말다래·유리잔 → 주인 스티커 놀이 → 전시대 배치/설명 스티커/별/실제 벽·바닥·조명 꾸미기 → 새 동료의 두 번째 무덤 초대 → 봉수형 유리병·금제 허리띠 발굴과 두 봉분의 지상 조사 → 둘째 주인/전시 확장. 지도에서 다음 탐험이 보이고 이미 얻은 전시·꾸미기는 누적된다. 동료 도움과 깜짝 토우를 발굴 중 실제로 사용한다.

오답은 토우의 창작 소품 동작으로 웃음을 만들며 실제 유물을 버리거나 망가뜨리지 않는다. 특정 왕·성별은 정답으로 삼지 않는다. 두 봉분은 땅속 유물로 파내지 않고 새의 관찰 장면으로 다룬다. 두 사람의 정확한 관계도 단정하지 않는다. 도판은 직접 그린다.

유물 하나의 그림 선택을 마치면 스티커를 얻는다. 주인에게 세 스티커를 붙이고 엉뚱한 현대 소품도 눌러 볼 수 있다. 실루엣은 상상이라고 표시한다. 박물관은 유물을 고르고 전시대를 누르는 방식으로 배치한다. 배치 1별, 획득한 설명 스티커를 붙이면 3별. 꾸미기 3종×3단계는 별에 따라 해금되며 별은 반복 클릭으로 늘어나지 않는다. 가상 손님은 반응만 주며 인기 점수는 없다.

기존 33개 테스트·보호된 발굴/입력/격자/대사/HUD 파일 유지. 새 진행·보상·저장·이전 전시 가져오기를 별도 모델 검사. 브라우저에서 두 무덤, 오답, 스티커, 전시·꾸미기·재접속까지 검증한다. 이번 작업으로 반 코드·온라인 공유·학급 서버까지 완료했다고 주장하지 않는다.

## 구현 기록

- 기본 진행의 긴 관찰·학습 연결·사례 판단을 새 모험 UI로 교체했다. 이전 모듈·저장은 보존한다.
- 두 무덤의 5개 유물과 1개 지상 조사, 그림 선택·짧은 소품 장난·스티커·전시·꾸미기·결말을 연결했다.
- 독립 최종 검토의 지적을 반영해 파던 층을 저장하고, 둘째 전시 설명을 모두 붙이기 전에는 결말에 들어가지 않게 했다.
- Ruling: 원안의 재방문 동기를 위해 지도에 완료한 유물 다시 파기를 추가했다. 본 탐험·전시·별을 보존하는 별도 놀이로 구현했으며 다시 파기의 중간 저장은 하지 않는다.
- Ruling: 자유 이름 입력은 이번 혼자 놀이 시제품에서 제안 별명 3개로 좁혔다. 입력·금지어 정책·학교 공유는 후속 범위이며 원안 전체 완성으로 표현하지 않는다.
- 모델 9개, 보호된 기존 33개, 이전 모듈 15개 통과. 새 브라우저 검사는 메모리 저장소로 실제 사용자 저장과 분리했다.

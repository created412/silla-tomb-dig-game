# 토우 직접 조작 모험 구현 계획

**Goal:** 토우를 직접 움직여 길을 열고 발굴한 뒤 다음 토우를 얻는 연속 모험을 배포한다.
**Architecture:** 기존 발굴 모델은 그대로 두고 독립적인 탐험 모델·캔버스 화면을 `main.js`의 explore 단계로 연결한다. 첫 금관 전 두꺼비, 금관 뒤 새, 이후 거북·뱀 순으로 조작 능력을 얻는다.
**Tech Stack:** 바닐라 ES 모듈, Canvas, Pointer Events. 새 의존성·유료 이미지 없음.
**Spec:** `docs/visual-review/activity-reference-2026-10-22.md`, 사용자의 “구현해” 승인.

## 제약·선택

- 보호 대상 5개 모듈과 prototype/tests는 수정하지 않는다. 새 검사는 checks에 둔다.
- 시간 제한 없이 낙하·돌 충돌은 근처 체크포인트에서 재시도한다. 발견한 빛 조각은 유지한다.
- 신라 무덤을 부수는 조작 대신 현장으로 가는 상상 속 길을 탐험한다. 실제 유물 정보는 기존 발굴 기억으로 연결한다.
- 5개 접근 구간: 두꺼비 점프 → 새 비행 → 거북 방어 → 뱀 좁은 길 → 네 친구 협동.
- 이동 좌/우 + 능력 버튼, 키보드 방향키/A·D + Space. 새는 누르는 동안 상승, 거북은 방어, 뱀은 낮추기. 화면 회전·탭 전환 시 눌린 입력을 해제한다.
- 처음에는 두꺼비만 있고 금관 완료 후 새를 얻도록 기존 합류 순서를 바꾼다. 이미 완료한 저장 기록도 이어 쓸 수 있다.
- 수동 저장 버튼으로만 기록한다. 이어가기와 새로 시작하기를 함께 제공하며 새 게임은 저장 전 기존 기록을 덮지 않는다.

## 검토 중점

1. 점프를 길게 누르면 자동 연속 점프하지 않고, 공중 점프는 제한한다.
2. 방향키·터치를 동시에 쓸 때 입력이 남지 않는다. 탭 숨김·정지·화면 전환으로 물리가 진행하지 않는다.
3. 보상을 얻거나 실패할 때 저장 기록을 자동으로 덮지 않는다.
4. 시작 지점·실패 지점에서 어떤 토우로도 막혀 재시도가 불가능해지지 않는다.
5. 모바일 HUD·버튼이 캐릭터와 발판을 가리지 않고, 발굴판 크기는 유지된다.

## 검증 기록

자동 검사와 독립 검토를 완료했다. 실제 브라우저는 연결 중단으로 제목 로딩만 확인했다. 상세 결과와 남은 화면 검증은 `docs/visual-review/active-adventure.md` 참조.

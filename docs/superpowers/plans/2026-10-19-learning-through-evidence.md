# 유물 수집을 생활 설명으로 연결하기

피드백: 세 유물을 찾고 전시하지만 무엇을 배웠는지 드러나지 않는다.

문제는 플레이 분량만이 아니다. 이전 화면은 설명을 먼저 주고 두 선택지 중 고르게 했으며, 마지막 설명판도 프로그램이 자동 작성했다. 학생이 근거를 선택해 설명하거나 새로운 상황에 적용한 결과가 없었다.

## 이번 구현 판단

기존 초등 5~6학년·바닐라 모듈·보호 파일 제약을 유지한다. 기획서의 생활 추론 목표를 행동으로 드러낸다. 학습 효과를 검증했다고 주장하지 않으며 실제 학생 반응은 후속 확인 대상이다.

세 유물과 이름의 불확실성을 확인한 뒤 ‘기억 공방’으로 간다. 학생이 생활 장면마다 유물과 근거 특징을 연결하면 상상 장면이 드러난다. 장면은 신분/말을 타는 생활/교류이며 실제 인물의 하루를 복원했다고 주장하지 않는다. 세 장면을 완성하면 다른 가상 무덤의 기록 두 건에 판단을 적용한다. 선택별 피드백과 재시도는 제공하되 첫 선택 기록은 유지한다.

전시에는 정해진 설명을 자동으로 붙이는 대신 학생이 완성한 유물-특징-생활 연결과 적용 결과를 보여 준다. 모든 연결과 적용을 완료해야 새 전시를 만들 수 있다. 기존 v1 전시는 그대로 열 수 있지만 새 활동을 했다는 표시를 소급해서 붙이지 않는다.

## 구현·검증

- 별도 learning-data/model/view 모듈로 장면 연결, 첫 판단, 수정 횟수, 저장 검증을 관리한다.
- 기존 story-model의 완료 조건과 저장 형식에 학습 기록을 연결한다. 기존 저장값 읽기 호환 유지.
- 원래 발굴 모듈과 prototype/tests는 손대지 않는다.
- 학습 단계의 우회 방지·불완전 근거·오답/중복 제출·첫 판단 유지·저장 위조/손상·기존 저장값을 별도 tools 테스트로 확인한다.
- 브라우저 전체 발굴→연결→새 사례→전시→재열람, 가로 태블릿에서 화면과 버튼을 확인한다.

## 콘텐츠 범위

세 지식: 화려한 금 장신구로 짐작하는 높은 지위, 안장 부속품으로 짐작하는 말과 관련된 생활, 먼 지역의 유사 유리그릇으로 짐작하는 물건의 교류. 금관의 미출토만으로 낮은 지위를 확정하지 않는다. 가상 사례는 실제 발굴 기록과 구분한다. 기존 고증 링크는 docs/visual-review/story.md에 있다.

## 구현 결과

- 학습 활동 없는 전시 완료를 거부하는 검사가 먼저 실패함을 확인하고, 완료 조건을 추가했다. 기존 33개와 확장 15개 테스트 통과.
- v2 기록에 세 연결과 두 사례의 첫 판단/수정 횟수를 저장한다. v1 전시 호환 유지.
- 독립 검토에서 오답 뒤 화면 위로 이동하는 문제가 발견됐다. 1024×600에서 제목으로 초점이 이동하고 스크롤이 0으로 초기화되는 것을 재현한 뒤, 오답 설명에 초점을 주고 화면 안에 보이도록 수정했다. 브라우저에서 설명에 초점이 있고 위·아래 경계가 화면 안에 있음을 확인했다.
- 실제 학습 효과의 판정은 남겨 둔다. 사용자의 강조점에 대한 선택 응답은 없었으므로, 기획서에 따라 신라 생활 내용과 근거로 추론하는 활동을 함께 구성했다.

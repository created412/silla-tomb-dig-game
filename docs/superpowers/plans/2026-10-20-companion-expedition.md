# 토우 능력 탐험과 쉬운 유물 이야기

사용자가 승인한 방향: 토우 획득이 보상이 되고, 각자의 특징을 직접 조작해 다음 구역을 연다. 두꺼비 점프와 새 공중 탐색을 우선 구현한다. 유물은 시대·출토 장소·종류/쓰임이 발견 장면에서 분명히 보여야 한다.

기술: 기존 바닐라 모듈·Canvas·정적 상대 경로를 유지한다. 보호된 dig-model/grid/input/dialogue/hud와 prototype/tests는 변경하지 않는다. 토우 능력은 새로운 입구/탐색 장면에 구현하고 실제 유물 마무리는 기존 붓질을 사용한다.

- [x] companion-model.js: 입구(두꺼비), 위에서 찾기(새), 돌 틈(거북), 둘째 언덕(새)의 순차 해금·보상·저장. 기존 저장의 소유 토우와 전시는 유지한다. 새 모험은 뱀 안내역과 시작해 두꺼비→새→거북을 획득한다.
- [x] companion-ui.js / companion.css: 묻힌 토우를 깨우는 획득 연출, 착지 지점을 직접 정하는 점프, 새를 방향키/터치 조작으로 이동시키는 탐색, 거북의 받침과 틈 조사. 실패는 재시도하며 진행·별을 잃지 않는다. 지도에서 능력 놀이를 다시 열 수 있다.
- [x] artifact-stories.js: 국립박물관·국사편찬위원회 자료로 시대·장소·용도·관찰거리 2개 작성. 직접 그린 유물 도판의 포인트를 누르면 토우의 짧은 농담과 설명을 보여 준다. 확인 문제를 추가하지 않는다.
- [x] main/adventure UI 연결: 경로를 열면 실제 발굴 진입, 발견 직후 유물 소개, 박물관에서 다시 보기. 기존 저장 마이그레이션과 전시 보존.
- [x] 보호 테스트 33개·모험 테스트 유지. 새 모델 해금/보상/취소/재접속 검사와 실제 브라우저 조작 확인. 최종 독립 검토 후 기존 초안 PR 갱신.

Ruling: 뱀은 안내역으로 처음부터 함께한다. 두꺼비·새를 핵심 조작으로, 거북을 세 번째 획득 보상과 돌 틈 조작으로 구현한다. 네 종류를 한꺼번에 깊게 만들기보다 승인받은 두 핵심 조작을 완성한다. 토우 능력과 가상 입구는 창작 놀이이며 실제 고고학 발굴 방법으로 설명하지 않는다.

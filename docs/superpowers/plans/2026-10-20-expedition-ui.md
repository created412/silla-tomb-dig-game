# 탐험 시작 선택과 UI 재구성

사용자 요청: 이어가기 옆에 새로 시작하기, UI 전반의 시각적 재설계. 별도 라이브러리 없이 기존 Canvas·ES 모듈과 보호 파일 제약을 유지한다.

- 첫 화면에 이어가기/새로 시작하기를 나란히 둔다. 새 모험은 메모리만 초기화하며 저장 버튼을 누르기 전까지 기존 기록을 보존한다. 타이머·토우 장면·이야기 화면의 임시 선택도 초기화한다.
- 밝은 청록, 짙은 잉크색, 금색을 기본으로 쓴다. 새로 그린 봉분·발굴터 SVG와 기존 토우 Canvas를 합쳐 첫 화면을 구성한다. 본문과 클릭 영역은 충분히 크게 유지한다.
- 탐험 지도는 경로가 이어지는 지도, 토우 메뉴는 획득 상태가 보이는 수집책, 유물 소개는 도판과 설명이 구분되는 관찰 화면으로 재구성한다. 발굴·능력·전시 화면의 버튼, 내비게이션, 저장 영역도 같은 디자인을 적용한다.
- 새 시작과 저장 보존 브라우저 검사, 기존 33개를 포함한 코드 검사, 전체 게임 검사, 데스크톱/태블릿/휴대폰 화면을 확인한다. 결과 화면과 초안 PR을 갱신한다.

디자인 선택은 구현자의 판단이다. 기존 저장을 삭제하지 않으므로 새 시작을 위한 별도 확인 창은 두지 않는다. 직접 그린 SVG/Canvas만 사용한다.

# 발굴 시제품 비주얼 개선 실행 계획

> For agentic workers: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 흙을 걷어 내는 과정과 금관 발견 순간이 읽히는 초등 5~6학년용 시제품.
**Architecture:** 기존 모델과 입력은 그대로 사용한다. 렌더러는 캐시한 재질을 불규칙한 구멍으로 깎고, 별도 캔버스 드로잉 모듈이 토우와 금관을 담당한다. main.js는 연출과 UI만 연결한다.
**Tech Stack:** Vanilla ES modules, Canvas 2D, CSS. 추가 의존성 없음.
**Spec:** docs/handoff/2026-10-19-codex-visual-redesign.md

## 진단과 디자인 결정

- 기존 테스트 33/33 통과. 발굴 모델보다 시각적 피드백이 주요 문제다.
- 셀 전체 알파 변경 때문에 층의 경계와 깊이가 흐리다. 동일한 재질을 이어 그리고 구멍으로 제거한다.
- 기존 발견 대기 300ms와 임시 금관을 2,600ms 등장 연출 및 직접 그린 금관 도판으로 바꾼다.
- 색: 깊은 청록 #173f3b, 밝은 청록 #34786b, 흙 #a87549, 진한 흙 #64452f, 금 #efc65d, 종이 #fff3d5.
- 글꼴: 설치된 둥근 계열 우선, Malgun Gothic/시스템 폴백. 외부 글꼴 로딩 없이 작동.
- 시작: 왼쪽 제목과 시작 버튼, 오른쪽 봉분과 토우. 발굴: 위 안내, 가운데 땅, 아래 양쪽 토우와 말풍선. 발견: 중앙 도판, 아래 친구와 대사.
- 창작 토우는 무광 점토색, 납작한 몸과 작은 눈. 실제 출토품을 복제했다고 주장하지 않는다. 사용자 요청에 따라 이 스타일을 1차 시안으로 구현한다.

## Global Constraints

- dig-model.js, grid.js, input.js, dialogue.js, hud.js, prototype/tests/ 수정 금지.
- 기존 수치, 단계 순서, localStorage 기록 유지. 한국어, 본문 20px, 버튼 44px 이상.
- 상대 경로만, 빌드/의존성 없음, 외부 이미지 없음. 직접 그린 벡터/캔버스만 사용.
- DPR 최대 2, 텍스처 캐시, 파티클 최대 100개, 100dvh 폴백, reduced-motion 대응.

## Review Focus

- 재시작 시 효과·반응 타이머가 남지 않아야 한다.
- 발견 연출 중 탭으로 만담이 건너뛰어지지 않아야 한다.
- DPR 2 및 작은 가로 화면에서도 토우·대사·발굴 영역이 겹치지 않아야 한다.
- 부분 제거/돌 균열/와르르 뒤 시각 상태가 모델과 일치해야 한다.
- 하위 경로 서비스 및 오프라인 상태에서 추가 자산 요청 오류가 없어야 한다.

## 검토 기록

- Ruling: 시제품의 시각 개선은 브라우저 전후 화면으로 검증하고 보호된 테스트는 변경하지 않는다. 발견 타이밍·재시작은 별도 포인터 통합 검사를 추가한다.
- Ruling: 6칸짜리 단일 행 모델에서는 금띠를 노출한다. 전체 금관 도판은 발견 장면에서 보여 주어 비율 왜곡을 피한다. 완전한 금관 윤곽을 땅에서 드러내는 방식은 추후 모델 변경이 필요하다.
- 독립 코드 검토: 타이머, 입력 잠금, 레이어 캐시와 마스크 복원, DPR, 상대 경로, 보호 파일 보존에서 조치가 필요한 문제 없음.
- 브라우저 검토 후 수정: 금관과 안내 글의 겹침 제거, 발견 장면에서도 캐릭터가 말풍선 밖에 있도록 배치, 부분 제거의 각진 모서리를 곡선으로 수정.
- 미검증: 실제 태블릿의 GPU/배터리/60fps, 공개 Pages에서 변경 버전 플레이, 어린이 반응. 로컬 CPU 비용은 실기기 FPS의 증거가 아니다.

배포 여부는 완료 보고에 명시한다. 공개 Pages에는 검증되지 않은 변경을 자동 배포하지 않는다.

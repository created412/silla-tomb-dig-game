# 첫 무덤 이야기 완결

사용자 요청: 금관 발견 뒤에 이야기가 이어져야 한다. 기존 0차 종료점을 확장한다.

## 흐름

잊어버린 주인을 찾아 달라는 토우의 부탁 → 금관 발굴 → 거북 합류 → 금관의 특징 관찰과 추론 → 나무 바닥의 말다래 발굴 → 원본 보존/복제 그림 관찰 → 유리잔 발굴 → 세 단서 종합 → 아직 모르는 이름을 구분 → 별명 선택 → 설명판이 있는 첫 전시 → 전시 재열람/다시 발굴.

첫 금관은 기존 흙·돌·나무 발굴을 유지한다. 후속 두 유물은 같은 무덤의 나무 바닥 구역이므로 흙과 돌이 걷힌 상태에서 살살 붓질한다. 입력·모델 수치는 유지한다. 토우의 가상 기억과 실제 유물의 근거를 분리하고 왕 이름·성별·직접 해외 방문을 확정하지 않는다.

## 구현

- [x] story-data.js: 유물 3개, 관찰 2개씩, 근거 선택·다시 보기, 전환 대사. 대사는 40자 이내.
- [x] story-model.js: 순서/중복 관찰/정답 단서/종합/저장 검증을 순수 함수로 분리. 별도 tools 테스트를 먼저 작성한다. 기존 prototype/tests는 변경하지 않는다.
- [x] story-ui.js 및 story.css: 관찰판·거북의 전환 장면·단서 보드·전시실. 가로 태블릿, 키보드, 저장 실패 대응.
- [x] artwork/characters/renderer: 말다래·남색 유리잔·거북 직접 그리기, 유물 종류별 발굴/발견.
- [x] main: found 뒤 story, 다음 발굴, 전시 및 재열람 연결. 기존 log 유지. 변경된 종료 흐름에 맞춰 브라우저 검증 도구 갱신.
- [x] 테스트33개 유지, 신규 순수 상태검사 8개, 포인터 전체3유물·오답·재시도·전시 저장/재열람 36개, 1024×600 게임 영역/DPR 2 확인.

## 범위와 판단

이번 결과는 첫 무덤의 로컬 단독 플레이 이야기다. 반 코드/서버/다른 아이의 박물관/둘째 무덤은 포함하지 않는다. 첫 전시를 결말로 삼고, 동작하지 않는 다음 무덤 버튼은 넣지 않는다. 별명은 세 가지 중 선택하여 자유 입력·공유·필터 구현을 요구하지 않는다. 화면에 저장 실패를 알리고 게임은 이어지도록 한다.

## 고증

- 말다래는 벽화가 아니다. 보존이 필요한 원본은 전문가에게 맡기고 복제 그림으로 관찰한다.
- 유리잔은 짙은 남색, 세로선과 거북등무늬. 먼 지역 교류를 짐작할 수 있지만 특정 제작국·주인의 직접 여행은 확정하지 않는다.
- 근거: 국립경주박물관 「천마, 다시 만나다」, 한국민족문화대백과사전 「천마총 유리잔」, 우리역사넷 「천마총」. 상세 링크와 사용 문장은 완료 보고에 기록한다.

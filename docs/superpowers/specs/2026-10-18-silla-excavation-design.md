# 신라 고분 발굴 게임 계획서

**가제: 《신라 발굴단: 천마총의 단서》**  
작성일: 2026-10-18 · 버전: 1.1 (2027학년도·2022 개정 기준 반영) · 상태: 기획, 구현 전

> 흙 속에 숨은 유물을 발견하고, 증거를 연결해 신라 사람들의 삶을 설명하는 중3 역사 발굴 추리 게임.

## 1. 기획 방향과 기본 전제

학생은 박물관의 청소년 연구원이 되어 천마총의 디지털 발굴 현장을 조사한다. 금관의 일부가 드러나는 순간의 기대감, 그림의 정체를 알아내는 발견, 근거를 연결해 해석을 완성하는 성취감을 핵심 재미로 삼는다. 마지막에는 자신이 만든 작은 전시관을 완성한다.

최종 임무는 **“이 무덤과 유물로 신라 사회에 관해 어디까지 말할 수 있을까?”**에 답하는 것이다. 특정 왕의 이름을 맞히는 결말 대신, 밝혀낸 사실과 아직 모르는 사실을 구별하는 연구 성과를 제시한다.

| 항목 | 1차 제안 |
|---|---|
| 대상 | 2027학년도 중학교 3학년 역사 학습자 |
| 교육과정 | 2022 개정 중학교 역사 |
| 활용 | ‘국가의 형성과 발전’ 중 삼국과 가야의 문화 학습·복습 — 신라 고분 중심 |
| 플랫폼 | 설치·로그인 없이 실행하는 PC·태블릿 웹 게임 |
| 장르 | 발굴 조작 + 관찰 퍼즐 + 증거 추리 + 전시 꾸미기 |
| 시각 방식 | 2D 발굴 평면과 단면 전환, 유물 확대 화면 |
| 플레이 | 기본 25분, 45분 수업 1차시 안에 토의·정리까지 완료 |
| 인원 | 개인 또는 2인 1기기, 두 명이면 조사원·기록원 역할 교대 |
| 배경 | 오늘날의 디지털 조사실 / 조사 대상은 삼국 시대 신라 고분 |
| 최종 산출물 | 근거가 연결된 전시 설명 3개와 개인 퇴장 질문 응답 |

플랫폼, 시간, 표현 방식은 기획자가 제안한 기본값이다. 사용자가 확정한 사항은 ‘신라 고분 발굴’, ‘2027학년도 중3용’, ‘2022 개정 교육과정·교과서 기준’, ‘재미와 교육성’, ‘계획서 우선’이다.

## 2. 교육과정·교과서 기준

### 적용 연도

**2027학년도 중학교 3학년용으로, 2022 개정 교육과정에 따른 중학교 역사②를 기준으로 한다.** 중3의 해당 교육과정 적용은 2027년 3월부터다. 실제 수업 시기와 교과서의 세부 단원명은 학교·채택 교과서에 맞춰 조정한다. [교육부 적용 일정](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0)

중심 성취기준은 ‘(8) 국가의 형성과 발전’의 **[9역08-03] “삼국과 가야가 남긴 문화의 특징을 분석한다.”**이다. 자료에 근거한 문화 분석을 중심에 두고, 교류의 관점에서 문화의 특징을 설명하도록 설계한다. 경기도교육청 공개 평가 자료에서도 이 성취기준과 자료 분석·교류 관점의 성취수준을 확인할 수 있다. [경기도교육청 중학교 역사 평가 자료, 인쇄 쪽수 34](https://www.goe.go.kr/resource/goe/na/bbs_2675/2025/09/0b74a0d9-16a7-48fe-81f1-d0058c77ffe8.pdf)

이 게임은 성취기준의 전체 범위 중 **신라 고분·유물 분석과 다른 문화 자료와의 비교·교류 해석**을 담당한다. 가야 문화와 삼국의 종교·학문 등은 별도 수업과 연결하며, 이 게임 하나로 ‘삼국과 가야의 문화’ 전체 성취기준을 이수·평가했다고 보지 않는다.

출판사·판본이 아직 지정되지 않아 특정 교과서의 본문 전체나 페이지를 직접 대조한 확정안은 아니다. 2022 개정 성취기준과 국사편찬위원회·박물관·국가유산 자료를 토대로 만든 초안이다. 출판사의 2022 개정 역사② 공개 자료에서도 ‘국가의 형성과 발전’ 구성을 확인했다. [해냄에듀 2022 개정 역사② 공개 자료](https://www.hnedu.co.kr/movie/view3.php?base_catcode=0&prdcode2=2405200004)

채택 교과서가 정해지면 구현에 앞서 **2022 개정판**의 ‘단원·쪽수 → 핵심 설명 → 게임 장면 → 확인 문항’ 대응표를 확정한다. 이전 교육과정의 교과서 분석 자료를 새 교과서의 내용·쪽수 근거로 사용하지 않는다.

### 성취기준을 게임에 반영하는 방식

유물 명칭을 고르는 데서 끝내지 않고 ‘관찰한 특징 → 근거 자료 → 문화적 의미 → 해석의 한계’를 연결하게 한다. 금관과 허리띠는 금속 공예·사회적 지위 분석, 천마도는 용도·표현 방식 분석, 황남대총 유리잔은 교류 관점의 분석에 활용한다. 삼국 고분 비교는 각 문화의 특징을 설명하기 위한 자료로 사용한다.

### 학습 목표와 게임 행동

| 학습 목표 | 학생의 게임 행동 | 학습을 확인하는 증거 |
|---|---|---|
| 돌무지덧널무덤의 구조를 설명한다 | 봉토·돌무지·나무덧널·널의 관계를 단면에서 조립한다 | 구조와 도굴의 어려움을 연결한 설명 |
| 유물로 신라의 사회·문화를 추론한다 | 금관의 재료와 장식을 관찰하고 무덤 규모 자료와 연결한다 | 지배층의 권력·금속 공예 기술에 관한 근거 있는 해석 |
| 삼국 고분의 대표 사례를 비교한다 | 천마총·고구려 벽화 고분·백제 무령왕릉 자료를 분류한다 | 재료·구조·그림 위치 중 두 기준으로 비교 |
| 대외 교류의 흔적을 설명한다 | 황남대총 유리그릇과 외부 지역 비교 자료를 연결한다 | 교류 가능성과 구체적 경로의 불확실성을 구분 |
| 관찰과 추론을 구별한다 | ‘확인한 사실·근거 있는 추정·아직 알 수 없음’ 칸에 설명을 배치한다 | 금관만으로 왕의 이름·성별·골품을 확정하지 않는 판단 |

위 표는 [9역08-03]을 이 게임의 범위에 맞게 구체화한 학습 목표다. 발굴 기록과 보존 태도는 게임의 탐구 활동 목표이며, 성취기준 문구 자체에 명시된 내용으로 표시하지 않는다.

## 3. 핵심 게임 흐름

**임무 받기 → 조사 구역 선택 → 층과 구조 확인 → 유물 노출·기록 → 확대 관찰 → 비교 자료 연결 → 전시 설명 완성**

### ① 도입: 빈 전시실의 의뢰 — 2분

박물관의 ‘신라 사람들은 어떤 삶을 살았을까?’ 전시에 설명이 비어 있다. 학생은 발굴·연구 자료를 통해 빈 설명을 채운다. 지도에서 경주를 확인하고, 시간띠에서 ‘삼국 시대 신라’ 구간을 선택한다.

첫 화면에 “실제 천마총의 구조와 출토 유물을 바탕으로 만든 교육용 가상 발굴입니다. 발굴 순서와 배치는 학습을 위해 단순화했습니다.”를 짧게 표시한다.

### ② 무덤의 구조를 열다 — 5분

상부 흙을 걷어 내면 돌무지가 나타나고, 단면 화면에서 나무덧널과 널의 관계가 드러난다. 실제 나무가 온전히 남아 있다고 보이지 않도록 ‘남은 흔적’과 ‘추정 복원선’을 구분한다. 복원선에는 색과 함께 점선·문자 표시를 사용한다.

학생은 조사 구역을 선택하고 기록한 뒤 다음 단계로 넘어간다. 흙 제거는 짧은 드래그 또는 버튼으로 수행한다. 돌무지는 전문 조사팀의 단계별 제거 연출로 표현한다. 학생이 곡괭이로 무덤을 부수거나 통로로 들어가는 장면은 두지 않는다.

끝에서 “다시 안으로 들어가기 어려운 까닭”을 구조 카드로 설명하면 무덤 단면 전시가 완성된다. 돌무지덧널무덤의 구조와 많은 노동력의 필요성은 우리역사넷의 천마총 설명을 따른다. [천마총 용어 해설](https://contents.history.go.kr/front/tg/view.do?levelId=tg_001_0240)

### ③ 세 유물을 조사하다 — 8분

발굴 구역에서 다음 세 유물을 찾는다. 발견 순서는 일부 선택할 수 있지만, 핵심 유물은 모든 학생에게 제공한다.

| 유물 | 조작·관찰 | 추리 임무 |
|---|---|---|
| 천마총 금관 | 표면의 일부가 드러난 뒤 조심스럽게 주변 흙을 제거하고 장식을 확대한다 | 화려한 금속 공예와 무덤 규모를 함께 보면 무엇을 추정할 수 있을까? |
| 천마총 금제 허리띠 | 장식 부분을 관찰하고 금관과 공통점을 찾는다 | 장신구가 무덤 주인의 사회적 지위 해석에 주는 단서는 무엇일까? |
| 천마총 장니 천마도 | 발견 시 보존 담당에게 인계를 선택하고, 조사실의 복제 이미지에서 그림과 용도를 확인한다 | 벽화일까, 말에 쓰인 물건의 그림일까? |

금관·허리띠·천마도의 실제 출토지는 각각 공식 유물 자료로 확인한다. [천마총 금관](https://www.heritage.go.kr/heri/cul/culSelectDetail.do?VdkVgwKey=11%2C01880000%2C37&pageNo=1_1_2_0), [천마총 금제 허리띠](https://www.heritage.go.kr/heri/cul/culSelectDetail.do?VdkVgwKey=11%2C01900000%2C37&pageNo=5_2_1_0), [천마총 장니 천마도](https://www.heritage.go.kr/heri/cul/culSelectDetail.do?VdkVgwKey=11%2C02070000%2C37&pageNo=1_2_1_0)

천마도처럼 약한 재질의 유물을 직접 문지르거나 조각내 맞추지 않는다. 퍼즐은 촬영된 이미지나 복제 자료에서 진행한다. 천마도는 말다래에 그려진 그림으로 설명하며, 그림의 상징을 하나의 확정된 종교 해석으로 채점하지 않는다. [우리역사넷 신라 문화 설명](https://contents.history.go.kr/front/km/view.do?levelId=km_005_0060_0020_0050)

### ④ 다른 무덤과 연결하다 — 6분

조사실에 들어오면 ‘내가 발굴한 유물’과 ‘다른 유적의 비교 자료’를 탭과 출토지 이름으로 구분한다.

- **삼국 비교 3분:** 고구려 벽화 고분의 돌방·벽면 그림, 백제 무령왕릉의 벽돌 구조, 신라 천마총의 돌무지·나무덧널을 비교한다. ‘나라당 무덤 양식 하나’로 일반화하지 않고 모두 대표 사례라고 표시한다. [고분 비교 설명](https://contents.history.go.kr/front/ta/print.do?levelId=ta_h71_0070_0010_0030_0010&whereStr=)
- **교류 조사 3분:** 황남대총 남분 출토 유리잔 카드와 형태·제작 특징에 관한 연구 설명을 함께 제공한다. 학생은 이를 ‘외부 세계와 이어진 교류의 단서’에 연결한다. 출토지만으로 직접 왕래나 단일 이동 경로가 입증된다는 선택에는 근거가 더 필요하다는 피드백을 준다. [국립중앙박물관 유리잔 설명](https://www.museum.go.kr/MUSEUM/contents/M0701010000.do?arcId=15083&catCustomType=united&catId=128&cp=&schM=view&sv=&unitedUse=)

교류 지도에는 관련 지역과 ‘추정되는 교류망’을 점선으로 보여 준다. 세부 도시 순서를 외우거나 하나의 경로를 정답으로 강제하지 않는다. 황남대총 유리잔을 천마총 발굴 보상으로 지급하지 않는다.

### ⑤ 나의 작은 신라 전시관 — 4분

학생은 전시 설명 세 개를 완성한다.

1. **무덤의 구조:** 구조 카드와 그 구조가 갖는 특징 연결.
2. **신라 사회와 문화:** 금속 장신구·무덤 규모를 근거로 설명하고, 삼국 고분의 차이 한 가지 덧붙이기.
3. **신라와 바깥 세계:** 황남대총 유리잔으로 교류를 설명하고 아직 확정하기 어려운 부분 표시.

설명은 ‘주장 카드 선택 → 근거 카드 연결 → 한계 표시’로 만든다. 선택 결과로 읽기 쉬운 문장이 자동 구성되며, 학생이 한 문장을 덧붙일 수 있다. 자유 서술은 자동 정오 채점하지 않고 교사가 읽는다.

완료 화면에는 전시관 이름·배치·배경색을 선택하는 보상이 열린다. 새로운 역사 사실이나 핵심 자료를 성적에 따라 잠그지 않는다.

## 4. 실제 플레이 장면 예시

흙 사이로 금빛 곡선이 드러난다. 학생이 해당 구역을 선택하면 주변 흙을 제거할 범위가 표시된다. 작업을 마치면 유물이 즉시 수집함으로 사라지는 대신, 사진과 위치를 기록하는 카드가 열린다.

금관을 확대해 관찰한 학생에게 다음 연구 의견이 제시된다.

> “금관이 있으니 이 무덤은 진흥왕의 무덤이다.”

학생은 의견을 ‘아직 알 수 없음’에 배치한다. 화면은 “금관은 높은 지위를 추정하는 단서가 될 수 있지만, 이것만으로 특정 왕의 이름을 알아낼 수는 없어요.”라고 설명한다.

이어 무덤 규모 자료를 연결해 “무덤의 규모와 금속 장신구는 높은 지위의 인물과 관련된 무덤으로 해석할 근거가 된다.”는 전시 문장을 완성한다. 금관의 가격 대신 **설명이 증거로 뒷받침되는 순간**에 보상 연출을 준다.

## 5. 재미·보상·실패 설계

| 장치 | 학생이 느끼는 재미 | 학습 기능 |
|---|---|---|
| 부분 노출 → 정체 공개 | 숨은 그림을 알아보는 발견 | 형태 관찰 |
| 발굴 구역 선택 | 내가 조사 순서를 정하는 주도성 | 관찰·기록 습관 |
| 추리 보드 | 증거를 연결하는 해결감 | 주장과 근거의 관계 |
| 의견 수정 | 틀린 추리를 더 나은 설명으로 바꾸는 성취감 | 증거에 따른 해석 수정 |
| 전시 꾸미기 | 내 결과물을 소유하는 만족 | 조사 내용 재구성 |
| 역할 교대 | 친구와 단서를 나눠 보는 재미 | 설명·협의 |

도구는 ‘상부 흙 조사’, ‘유물 주변 정밀 조사’, ‘기록’, ‘보존 인계’처럼 역할이 다르게 보이도록 구성한다. 드래그와 버튼 방식은 결과·보상이 같고, 연타 속도에 따른 이점은 없다.

**실패 처리:** 부적절한 도구를 선택하면 손상되기 직전에 안내하고 다시 선택하게 한다. 잘못된 연결에는 관련 증거를 다시 보여 주고 수정할 수 있게 한다. 첫 시도와 수정 후 결과는 구분해 남긴다. 필수 유물이 사라지거나 재시작해야 하는 실패는 없다.

**보상 기준:** ‘꼼꼼한 기록’, ‘근거 있는 해석’, ‘열린 판단’ 세 배지를 사용한다. 기록 배지는 세 유물의 위치·사진 기록, 해석 배지는 전시 설명 세 개의 유효한 근거 연결, 열린 판단 배지는 이름·교류 경로에 관한 판단 유보로 획득한다. 도움말을 사용해도 배지를 받을 수 있다. 전시 완성만으로 꾸미기 기본 기능을 모두 연다.

**반복 플레이:** 조사 순서, 비교 자료 제시 순서, 추가 관찰 질문을 바꾼다. 실제 유물의 출토지나 핵심 역사 사실은 무작위로 바꾸지 않는다.

## 6. 수업 운영안과 평가

| 시간 | 활동 | 교사 역할 |
|---|---|---|
| 0~5분 | ‘무덤으로 무엇을 알 수 있을까?’ 사전 질문, 접속·역할 배정 | 사전 지식과 조작 준비 확인 |
| 5~30분 | 기본 게임 25분 | 막힌 조 관찰, 중간 역할 교대 안내 |
| 30~38분 | 전시 설명 공유·비교 | 같은 유물로 가능한 주장과 과도한 주장을 비교 |
| 38~43분 | 개인 퇴장 질문 3개 | 모둠 성과와 개인 이해 구분 |
| 43~45분 | 저장·정리 | 다음 수업 연결 |

퇴장 질문은 다음과 같이 구성한다.

1. 돌무지덧널무덤의 구조가 유물 보존과 어떤 관련이 있는지 설명하라.
2. 천마도와 고구려 고분 벽화는 그림이 있는 ‘대상·위치’가 어떻게 다른가?
3. 신라 고분의 외래계 유리그릇으로 알 수 있는 것과 추가 증거가 필요한 것을 하나씩 쓰라.

형성평가는 [9역08-03]의 문화 특징 분석을 확인하기 위해 ‘구조·비교 이해’, ‘주장과 근거’, ‘교류 해석’, ‘불확실성 구분’의 네 항목을 각각 0~2점으로 관찰한다. 0점은 근거를 제시하지 못한 상태, 1점은 자료는 찾았으나 설명이 불완전한 상태, 2점은 자료와 설명을 적절히 연결한 상태다. 총 8점은 이 게임의 학습 범위에 한정된 피드백용 예시이며, 교육과정 전체의 공식 성취수준이나 수행평가 점수로 직접 환산하지 않는다. 수행평가 성적 반영은 별도 수업 평가계획에서 정한다. 조작 속도·힌트 횟수는 역사 이해 점수에 반영하지 않는다.

교사용 화면에는 진행 단계, 처음 고른 설명, 수정 후 설명, 학생 추가 문장, 유물·설명 출처를 표시한다. 첫 버전은 기기 안에 기록하고 결과 요약을 인쇄하거나 텍스트 파일로 저장한다. 중앙 서버 수집·실시간 학급 대시보드는 확장 기능으로 둔다.

## 7. 화면·접근성·분위기

핵심 화면은 시작·임무, 발굴 현장, 유물 관찰, 비교·추리 보드, 전시관·결과의 다섯 종류다.

- 발굴 화면: 중앙에 조사 구역, 왼쪽에 단계별 도구, 오른쪽에 기록 수첩, 아래에 현재 할 일 한 문장.
- 유물 화면: 확대 이미지와 관찰 지점, 재료·용도·출토지. 최초 공개는 2~3문장으로 제한하고 더 읽기를 제공한다.
- 추리 화면: 주장·근거·판단 수준을 순서대로 선택한다. 복잡한 선 연결 대신 카드 선택으로도 완료할 수 있다.
- 색채: 흙빛·짙은 남색·절제된 금색. 금빛 발견 연출은 강조하되 모든 화면을 반짝이게 하지 않는다.
- 소리: 흙 걷는 소리·종이 넘기는 소리·짧은 발견 효과음. 음소거로도 모든 정보를 이해할 수 있게 한다.
- 조작: 마우스·터치·키보드 선택을 지원하고, 드래그 대체 버튼·글자 확대·동작 줄이기를 제공한다. 목표 터치 영역은 최소 44px로 잡는다.

2D 방식을 제안하는 이유는 고분 단면과 출토 위치를 명료하게 보여 주면서 학교 기기의 조작 부담을 줄일 수 있기 때문이다. 3D 탐험은 후속 확장으로 검토한다.

## 8. 역사 고증 원칙

1. 천마총은 실제 유적이며, 게임 속 조사 순서·간격·노출 연출은 교육용 재구성임을 표시한다. 실제 발굴 당시의 장면을 정확히 재현했다고 주장하지 않는다.
2. 돌무지덧널무덤은 봉토·돌무지·나무덧널·널의 공간 관계로 보여 준다. 층 구성을 단순한 수평 지층 네 장으로 그리지 않는다.
3. 천마도를 벽에 그려진 벽화로 표현하지 않는다. 유물 카드마다 명칭·재질·출토지·확인된 설명·해석·출처를 분리한다.
4. 금관 출토만으로 특정 왕·성별·정확한 골품을 확정하지 않는다. 금관의 실제 착용 방식처럼 논의가 있는 문제는 필수 정답에서 제외한다.
5. 신라의 모든 무덤을 돌무지덧널무덤으로 일반화하지 않는다. 고구려·백제 역시 대표 사례를 비교한다고 표시한다.
6. 통일 신라의 불국사·석굴암을 이 고분의 부장품이나 같은 발굴 시기의 자료로 섞지 않는다. 불교·골품제는 교과서 연결 설명에서 다룰 수 있지만 고분 유물만으로 제도 전체를 입증하지 않는다.
7. 유리그릇의 외래적 특징과 이동 경로의 추정을 구분한다. 연구 자료가 제시한 불확실성을 게임 정답에서도 유지한다.
8. 국사편찬위원회의 ‘역대 교과서’ 자료는 역사 설명의 보조 근거로 사용하고, 현행 교과서 판본을 직접 확인한 것으로 표기하지 않는다.

출시 전에는 실제 사용할 사진·도판별 이용 조건과 출처 표기를 확인한다. 생성형 이미지를 사용한다면 배경·인물·연출에 우선 쓰고, 정답 판단에 필요한 유물 형태·무덤 구조는 공식 자료와 대조한 도해로 제작한다.

## 9. 개발 범위와 제작 순서

### 첫 수업용 완성판에 포함

- 천마총 기반 교육용 발굴 현장 1개, 단면 보기.
- 금관·금제 허리띠·천마도 핵심 유물 3개.
- 고구려 벽화 고분·백제 무령왕릉 비교 카드, 황남대총 유리잔 교류 자료.
- 세 전시 설명을 만드는 추리 보드와 피드백.
- 25분 기본 진행, 단계별 도움말, 교사가 같은 기기에서 선택하는 단계 건너뛰기.
- 기기 내 자동 저장·이어하기, 새 활동 시작, 결과 인쇄·텍스트 저장.
- 학생용 용어 풀이와 교사용 정답·근거·출처 안내.

실시간 멀티플레이, 전투·도굴 경쟁, 유물 거래, 희귀도 뽑기, 로그인 계정, 생성형 AI 자유 대화, 사실적인 대형 3D 월드, 서버 기반 학급 관리 기능은 첫 버전 범위에서 제외한다.

### 권장 제작 단계

| 단계 | 산출물 | 다음 단계로 가는 조건 |
|---|---|---|
| 1. 내용 설계 | 2022 개정 채택 교과서와 [9역08-03] 대응표, 유물 자료표, 카드·피드백 문안 | 역사 사실·추론·재구성이 구분되고 2027학년도 사용 판본과 일치함 |
| 2. 조작 시제품 | 구조 확인 → 금관 발견 → 근거 연결까지 5분 분량 | 설명 없이도 다음 행동을 이해하고 발굴의 재미를 느끼는지 확인 |
| 3. 수업용 완성판 | 필수 유물·비교·교류·전시·저장 구현 | 처음부터 결과 저장까지 한 기기에서 완료 |
| 4. 수업 검증·수정 | 교사 검토, 학생 소규모 사용 기록, 수정본 | 아래 성공 기준 확인 |

제작 기간·비용은 그림 제작 방식과 개발 담당 인원이 정해진 뒤 산정한다. 구현 담당자는 라이브러리·파일 구조·애니메이션 방식 등을 선택할 수 있으나, 필수 학습 흐름·고증 원칙·저장 범위는 유지한다.

### 검증 목표

- 첫 행동을 시작할 때 장문 설명이 필요하지 않고, 학생이 발굴·기록·관찰의 차이를 말할 수 있다.
- 소규모 수업 검증에서 학생 80% 이상이 25분 안에 기본 전시를 완성하는 것을 목표로 한다. 이는 기대 목표이며 검증된 성과가 아니다.
- 사전·사후 질문에서 ‘천마도는 벽화’, ‘금관이면 특정 왕 확정’, ‘유리잔이면 직접 교역 확정’ 같은 오개념의 변화를 확인한다.
- 처음 틀려도 도움말과 재시도로 필수 학습을 모두 경험할 수 있다.
- 실제 학교 PC·태블릿에서 전체 진행·음소거·키보드/터치·새로고침 후 복구·결과 저장을 확인한다.
- 발굴만 재미있고 추리를 건너뛰려는 경향이 강하면 글을 늘리기보다 증거 선택과 전시 변화의 연결을 개선한다.

## 10. 후속 확장

첫 버전의 학습 효과와 조작 재미를 확인한 뒤, 황남대총의 유리그릇을 중심으로 한 두 번째 사건, 삼국 고분 비교 사건, 통일 전후 무덤 문화 변화, 학급 공동 전시를 차례로 확장한다. 각 사건은 새로운 유물 수집량보다 새로운 역사 질문을 중심으로 구성한다.

**기획의 중심 문장:** “발굴에서 발견의 재미를, 추리에서 역사적 사고를, 전시에서 배운 내용을 자기 말로 설명하는 경험을 만든다.”
